# Worked example (illustrative)

> **These files are illustrative of the formats, not real citations.** They show
> what a filled paper record, cache entry, viewpoint file, and deliverable look like
> so you can see the whole loop end-to-end. Delete or ignore them for real studies.

Files:
- `examples/P-9999.md` — a filled paper record
- `examples/cache-P-9999.md` — the matching cache entry
- `examples/viewpoint-example.md` — a filled viewpoint record
- `examples/library-example.bib` — the matching BibTeX entry (skill output)
- `examples/deliverable-example.md` — a short sample output with viewpoint map + MPA

Note how the deliverable cites `[P-9999]`, which maps to the paper record, which
maps to the cache entry, which maps to a DOI/URL — and the same key `P-9999` is the
BibTeX cite key in `library-example.bib`. That is the traceability chain.
