# Study: <your-object>

> This folder is a **copy of `studies/_template/`**. Rename the folder to your study
> slug and fill in the files below. Keep the filenames — the agents rely on them.

## Files in a study folder

- `workplan.md` — the research brief (fill this first; copy from the repo-root `workplan.md`).
- `notes.md` — free-form human notes and decisions.
- `fetch-requests.md` — queue of Fetch Requests from Author/Critic to Researcher.
- `round-summary.md` — what each round produced.

## How this study maps to the shared repo

- Cached sources go to the shared `cache/`.
- Paper records go to the shared `papers/`.
- IDs come from the shared `references/id-registry.md`.
- Deliverables go to `outputs/`.

> If you want fully isolated studies, copy the whole repo per study instead and keep
> `cache/`, `papers/`, `references/` local to each copy.
